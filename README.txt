SCIENCE LAB APP VERSION
This version is prepared as an installable Progressive Web App (PWA).
For installation in Chrome, the site must be served from HTTPS (for example, Netlify)
or localhost. Opening index.html directly from Files can test the simulations, but
Chrome may not show the Install App option for a local file.
